# 🦍 Gorilla Workout — Mobile App Showcase

[![Get it on Google Play](https://img.shields.io/badge/Google_Play-414141?style=for-the-badge&logo=google-play&logoColor=white)](https://play.google.com/store/apps/details?id=com.koznotech.gorillaworkout)

> **Note:** The core source code for this application is proprietary as it is a live, commercial product on the Google Play Store. This repository serves as a technical and visual showcase of the project's architecture and design.

---

## 📌 Project Overview
**Gorilla Workout** is a comprehensive Street Workout and Calisthenics mobile application developed entirely from scratch using **Flutter**. 

As a **solo developer**, I managed the complete software lifecycle—from UI/UX design and custom character animations to database architecture and Google Play deployment. The application provides professional training programs, exercise tracking, and a seamless user experience tailored for bodyweight athletes.

---

## 🛠️ Engineering & Development Highlights

### 1. End-to-End Product Ownership
* **Zero Pre-Made Assets:** Designed and animated every character, movement description, and UI element independently.
* **Full-Stack Execution:** Handled frontend mobile development, backend database structuring for professional training regimens, and the final production release pipeline.

### 2. Software Architecture & UX
* **Scalable Localization (i18n):** Architected a dynamic multi-language system. Currently supporting fully localized English and Turkish (including all complex exercise descriptions), with a codebase designed for rapid integration of future languages.
* **Responsive UI/UX:** Built a clean, intuitive, and highly responsive interface using Flutter's widget tree, ensuring smooth 60 FPS performance and seamless state management across a wide range of Android devices.
* **Data Management:** Integrated a robust database system to efficiently store, retrieve, and display structured workout programs and user progress.
